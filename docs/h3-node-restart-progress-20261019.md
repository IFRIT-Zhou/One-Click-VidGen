## 改动

只修改集群服务端与节点适配器，客户端源码不变：

- API 快照新增 `stage/message`，分别显示云端排队、派发中、节点已接收（加载模型或生成视频）、连接状态待核对和终态。保持原 `status` 枚举兼容。现有客户端会读取 `message`，其通用顶层“运行中”标签仍属于客户端 UI。
- 节点在发送请求前持久化 Linux `boot_id`。原任务既无历史又不在队列、且确认 boot 已变化时，报告 `WORKER_RESTARTED`，不额外停止新容器，不自动重提任务。
- 同一 boot 的不确定提交及缺少旧 boot 记录的历史任务，继续保留原来的防重复执行隔离逻辑。
- 云端仅传递固定白名单中的错误原因，避免将节点原始异常或凭据暴露给客户端；停止、重启、工作流错误、推理失败、结果校验失败可以区分。
