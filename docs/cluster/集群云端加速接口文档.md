# 集群云端加速接口文档

> 文档状态：以 2026-08-04 已部署接口为基线；标为“目标”的行为尚未全部实现。<br>
> 当前 HTTPS Base URL：`https://oneclickvidgen.com/api/v1`<br>
> 原公网 IP HTTP 地址只用于跳转，不再作为客户端配置。<br>
> 服务端剩余工作见
> [《集群端待完善清单》](./集群端待完善清单_2026-08-01.md)。

## 1. 基本信息

生产环境要求：

```text
Base URL: https://oneclickvidgen.com/api/v1
Content-Type: application/json
Authorization: Bearer <access_token>
```

除文件上传接口使用 `multipart/form-data` 外，其余请求默认使用 `application/json`。

本地 GPU 模式不调用这些接口。以下接口只用于用户选择集群 GPU 加速后的云端流程。

目标统一响应错误格式：

```json
{
  "code": "INSUFFICIENT_CREDITS",
  "message": "积分不足",
  "request_id": "req_xxx",
  "details": {}
}
```

当前未捕获异常已经使用上述结构，并返回 `X-Request-ID`；部分参数、认证和业务错误仍
由 FastAPI 返回 `{"detail": "..."}`。客户端现阶段必须兼容两种格式，服务端后续应
统一为目标格式。

常见 HTTP 状态码：

| 状态码 | 含义 |
|---:|---|
| `400` | 参数错误 |
| `401` | 未登录或 Token 无效 |
| `403` | 无权限、配额不足或账户被禁用 |
| `404` | 资源不存在或不属于当前用户 |
| `409` | 幂等冲突、状态冲突或余额锁定失败 |
| `413` | 文件或任务超过限制 |
| `415` | 不支持的媒体类型 |
| `422` | 音频可解码但不符合参考音色要求 |
| `429` | 触发限流或并发配额 |
| `500` | 服务端错误 |
| `503` | Ray/依赖服务暂不可用 |

## 2. 认证接口

### 2.1 注册

```http
POST /auth/register
```

请求：

```json
{
  "email": "user@example.com",
  "password": "strong-password",
  "captcha_token": "optional-captcha"
}
```

响应 `201`：

```json
{
  "user": {
    "id": "usr_xxx",
    "email": "user@example.com",
    "status": "active"
  },
    "verification_required": false
}
```

当前 staging 直接激活账户，尚未发送验证邮件；`captcha_token` 字段也尚未做服务端
验证。密码只能通过 HTTPS 发送，服务端不得保存明文密码。HTTPS 已启用；正式开放
注册前仍必须完成限流、邮箱验证或明确的邀请注册机制。

### 2.2 登录

```http
POST /auth/login
```

请求：

```json
{
  "email": "user@example.com",
  "password": "strong-password"
}
```

响应：

```json
{
  "access_token": "eyJ...",
  "token_type": "Bearer",
  "expires_in": 900,
  "refresh_token": "rt_xxx",
  "user": {
    "id": "usr_xxx",
    "email": "user@example.com"
  }
}
```

### 2.3 刷新 Token

```http
POST /auth/refresh
```

请求：

```json
{
  "refresh_token": "rt_xxx"
}
```

刷新成功后应返回新的 Refresh Token，旧 Token 失效。

### 2.4 当前用户

```http
GET /users/me
Authorization: Bearer <access_token>
```

响应：

```json
{
  "id": "usr_xxx",
  "email": "user@example.com",
  "status": "active",
  "created_at": "2026-01-01T00:00:00Z"
}
```

### 2.5 退出登录

```http
POST /auth/logout
```

请求：

```json
{"refresh_token": "rt_xxx"}
```

成功返回 `204 No Content`，服务端撤销对应 Refresh Token。

## 3. 配额和积分接口

### 3.1 查看余额和配额

```http
GET /account/summary
Authorization: Bearer <access_token>
```

响应：

```json
{
  "credits": {
    "available": 1200,
    "reserved": 30,
    "consumed": 870
  },
  "quota": {
    "max_concurrent_jobs": 2,
    "running_jobs": 1,
    "daily_characters_limit": 10000,
    "daily_characters_used": 2400,
    "max_queue_jobs": 5
  }
}
```

`running_jobs` 当前统计 cloud-api 中 `running` 和 `finalizing` 状态的任务，不等于 GPU
数量，也不等于单任务分块并行数。当前还没有返回 `queued_jobs`，且
`cancel_requested` 尚未计入占槽统计；严格口径和 Worker 原子调度属于待完善项。

### 3.2 查看积分账单

```http
GET /wallet/ledger?page=1&page_size=20&type=all
Authorization: Bearer <access_token>
```

响应：

```json
{
  "items": [
    {
      "id": "led_xxx",
      "type": "consume",
      "amount": -10,
      "balance_after": 1190,
      "reference_type": "cloud_job",
      "reference_id": "job_xxx",
      "created_at": "2026-01-01T00:00:00Z"
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 1
}
```

### 3.3 获取任务报价

```http
POST /cloud/quotes
Authorization: Bearer <access_token>
```

请求：

```json
{
  "chunks": [
    {"index": 0, "text": "待生成文本"}
  ],
  "voice": {"type": "uploaded", "id": "voice_xxx"},
  "audio": {"sample_rate": 24000},
  "gpu_acceleration": true
}
```

响应：

```json
{
  "quote_id": "quote_xxx",
  "estimated_credits": 10,
  "expires_at": "2026-01-01T00:05:00Z",
  "limits": {
    "max_chunk_chars": 1000,
    "max_total_chars": 5000
  }
}
```

报价仅供展示，最终预扣金额由服务端在创建任务时重新计算。

`voice.type` 当前支持 `preset` 和 `uploaded`。使用 `uploaded` 时，服务端确认该音色
属于当前用户且状态为 `active`。当前不可用音色返回 `422`；目标实现应补充稳定业务码，
并避免通过错误差异泄露其他用户的音色信息。

## 4. 充值接口

### 4.1 创建充值订单

```http
POST /recharge/orders
Authorization: Bearer <access_token>
Idempotency-Key: recharge-client-unique-id
```

请求：

```json
{
  "product_id": "credits_1000",
  "payment_provider": "wechat"
}
```

响应：

```json
{
  "order_id": "ord_xxx",
  "status": "pending",
  "amount_fen": 990,
  "credits": 1000,
  "payment": {
    "provider": "wechat",
    "qr_code": "weixin://wxpay/bizpayurl?..."
  },
  "expires_at": "2026-01-01T00:30:00Z"
}
```

服务端必须保证同一个 `Idempotency-Key` 不会创建多个有效订单。

当前 staging 只实现 `payment_provider=mock`；微信、支付宝等真实 Provider 尚未接入，
production 禁止使用 Mock 支付。

### 4.2 查询充值订单

```http
GET /recharge/orders/{order_id}
Authorization: Bearer <access_token>
```

响应：

```json
{
  "order_id": "ord_xxx",
  "status": "paid",
  "amount_fen": 990,
  "credits": 1000,
  "paid_at": "2026-01-01T00:10:00Z"
}
```

订单状态：`pending`、`paid`、`expired`、`refunded`、`cancelled`。

### 4.3 支付平台回调

```http
POST /payments/{provider}/notify
```

该接口不使用用户 Token，而使用支付平台签名验证。服务端必须校验：

- 签名
- 商户号
- 商户订单号
- 支付金额
- 支付状态
- 回调事件 ID

重复回调必须返回成功但不能重复增加积分。

## 5. 参考音色接口

### 5.1 查询音色列表

```http
GET /cloud/voices?type=all&page=1&page_size=50
Authorization: Bearer <access_token>
```

查询参数：

- `type`：`all`、`preset` 或 `uploaded`，默认 `all`。为兼容旧客户端，当前也接受
  `custom` 并按 `uploaded` 处理。
- `page`：从 `1` 开始。
- `page_size`：默认 `50`，最大 `100`。

响应：

```json
{
  "items": [
    {
      "id": "voice_01.wav",
      "type": "preset",
      "display_name": "预置音色 01",
      "status": "active",
      "preview_url": "/api/v1/cloud/voices/voice_01.wav/audio"
    },
    {
      "id": "voice_xxx",
      "type": "uploaded",
      "display_name": "我的旁白音色",
      "status": "active",
      "audio": {
        "format": "wav",
        "size_bytes": 602000
      },
      "created_at": "2026-01-01T00:00:00Z"
    }
  ],
  "page": 1,
  "page_size": 50,
  "total": 2,
  "default_voice_id": "voice_01.wav",
  "capabilities": {
    "preset": true,
    "preview_preset": true,
    "upload": true,
    "delete_upload": true
  },
  "limits": {
    "max_uploaded_voices": 20,
    "uploaded_voices_used": 1,
    "max_voice_bytes": 20971520
  }
}
```

`uploaded` 当前只返回当前用户自己的 `active` 音色。预置音色列表只包含服务端当前
启用的音色。客户端不传音色时使用 `default_voice_id`；接口不得返回 MinIO 对象键、
永久下载地址或其他用户的音色信息。

### 5.2 试听预置音色

```http
GET /cloud/voices/{voice_id}/audio
Authorization: Bearer <access_token>
```

仅接受当前启用的 `preset` 音色 ID。成功返回 `audio/wav`，并使用
`Content-Disposition: inline`，用于客户端播放器直接试听。该接口读取 cloud-api 上的
只读预置音色副本，不创建 TTS 任务、不扣积分，也不占用 GPU 任务并发。

客户端应优先读取列表中的 `preview_url`，播放前仍由本地后端携带云端 Token 代理请求，
不能把 Access Token 放进浏览器 URL。未登录返回 `401`，未知、已停用或试听文件缺失返回
`404`。当前接口只开放预置音色试听，不提供用户上传原始参考音频的下载能力。

### 5.3 上传参考音色

```http
POST /cloud/voices
Authorization: Bearer <access_token>
Idempotency-Key: voice-upload-client-unique-id
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `file` | file | 是 | WAV、MP3 或 FLAC，当前最大 20 MiB |
| `display_name` | string | 是 | 用户可见名称，1-80 个字符 |

请求示例：

```bash
curl -X POST "https://oneclickvidgen.com/api/v1/cloud/voices" \
  -H "Authorization: Bearer <access_token>" \
  -H "Idempotency-Key: voice-upload-001" \
  -F "file=@my_voice.wav;type=audio/wav" \
  -F "display_name=我的旁白音色"
```

首次创建响应 `201`：

```json
{
  "voice": {
    "id": "voice_xxx",
    "type": "uploaded",
    "display_name": "我的旁白音色",
    "status": "active",
    "audio": {
      "format": "wav",
      "size_bytes": 602000
    },
    "created_at": "2026-01-01T00:00:00Z"
  },
  "deduplicated": false
}
```

当前服务端检查扩展名、实际字节数和 SHA-256，随后交给 Ray 持久化；响应成功后，该
音色可以立即用于报价和创建任务。真实格式探测、解码、3-30 秒时长、静音检测和统一
标准化属于正式上线前的待完善项。

幂等和去重规则：

- 同一用户使用相同 `Idempotency-Key` 重试时，当前返回第一次创建的音色。
- 目标行为：同一幂等键对应不同文件或名称时返回 `409 IDEMPOTENCY_CONFLICT`。当前
  尚未比较重试内容，不能依赖该冲突检测。
- 同一用户使用不同幂等键上传相同 SHA-256 的音频，返回已有音色和
  `deduplicated=true`，不重复占用音色数量与存储配额。
- 服务端不得向其他用户暴露文件哈希是否已经存在。

上传可能返回的业务错误：

| HTTP | `code` | 含义 |
|---:|---|---|
| `409` | `IDEMPOTENCY_CONFLICT` | 目标行为：幂等键对应的内容发生变化 |
| `413` | `VOICE_FILE_TOO_LARGE` | 实际上传字节数超过限制 |
| `413` | `VOICE_QUOTA_EXCEEDED` | 当前为音色数量不足；总存储配额待实现 |
| `415` | `VOICE_FORMAT_UNSUPPORTED` | 当前按文件扩展名判断格式 |
| `422` | `VOICE_AUDIO_INVALID` | 目标行为：损坏、静音或没有有效音频流 |
| `422` | `VOICE_DURATION_INVALID` | 目标行为：解码后时长不在允许范围内 |
| `429` | `VOICE_UPLOAD_RATE_LIMITED` | 目标行为：上传频率超过限制 |

### 5.4 查询音色详情

```http
GET /cloud/voices/{voice_id}
Authorization: Bearer <access_token>
```

响应中的音色对象与上传接口一致。自定义音色不存在、已删除或不属于当前用户时返回
`404`。详情接口不返回原始参考音频地址；预置音色试听使用 5.2 的专用接口。

### 5.5 删除自定义音色

```http
DELETE /cloud/voices/{voice_id}
Authorization: Bearer <access_token>
```

成功响应 `204 No Content`。删除规则：

- 只能删除当前用户自己的 `uploaded` 音色，预置音色不能由用户删除。
- 被 `created`、`queued`、`running`、`finalizing` 或 `cancel_requested` 任务引用时，
  返回 `409 VOICE_IN_USE`。
- 删除成功后不能再用于报价或新任务。任务音色完整快照尚未实现。
- 不存在、已删除或不属于当前用户时统一返回 `404`。

## 6. 云端任务接口

### 6.1 创建云端任务

```http
POST /cloud/jobs
Authorization: Bearer <access_token>
Idempotency-Key: client-job-unique-id
```

请求：

```json
{
  "client_job_id": "local-client-job-001",
  "chunks": [
    {"index": 0, "text": "第一段文本"},
    {"index": 1, "text": "第二段文本"}
  ],
  "voice": {
    "type": "uploaded",
    "id": "voice_xxx"
  },
  "emotion": {
    "name": "calm",
    "weight": 0.65
  },
  "audio": {
    "speed": 1.0,
    "volume": 1.0,
    "pitch": 0,
    "sample_rate": 24000,
    "channels": 1
  },
  "scheduling": {
    "max_parallel_chunks": 2
  }
}
```

响应 `202`：

```json
{
  "job_id": "job_xxx",
  "status": "queued",
  "reserved_credits": 10,
  "status_url": "/api/v1/cloud/jobs/job_xxx"
}
```

当前服务端会在事务中完成配额检查、积分预扣、任务写入和幂等处理。使用上传音色时会
校验归属和状态，但“锁定音色记录并保存元数据快照”尚未完成；这是防止任务创建与音色
删除竞态的目标行为。

账户并发上限不应阻止合法任务进入队列。目标流程是在 cloud-api Worker 真正领取任务
时原子检查账户执行槽；当前版本只在创建接口检查，尚未形成严格调度闭环。

## 8. 客户端典型流程

```text
本地模式
  -> 直接使用本地 GPU

云端模式
  -> 登录
  -> GET /account/summary
  -> GET /cloud/voices
  -> 可选：POST /cloud/voices 上传参考音色
  -> POST /cloud/quotes
  -> POST /cloud/jobs
  -> 轮询 GET /cloud/jobs/{id}
  -> GET /cloud/jobs/{id}/chunks/{index}/audio
```

客户端只能根据服务端返回的任务状态和结果 URL 处理结果，不能自行修改积分、任务
状态或费用。
