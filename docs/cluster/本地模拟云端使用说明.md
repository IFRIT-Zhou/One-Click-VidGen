# 本地模拟云端使用说明

这套模拟服务用于在正式服务器上线前验证登录、积分、云端音色、任务排队、失败退款、
取消和音频下载。它与正式 `cloud-api` 使用同一套客户端接口，但所有数据只保存在本机
内存中，不会产生真实费用。

## 一键启动

1. 先关闭正在运行的 One-Click VidGen 启动窗口。
2. 双击根目录的 `start_mock_cloud_test.bat`。
3. 脚本会同时启动模拟云端、后端和前端，并打开模拟云端说明页。
4. 在 One-Click VidGen 右上角点击“登录”。

关闭启动窗口后，模拟云端和本地前后端会一起停止。正常的 `start_windows.bat` 不会
启用模拟云端。

## 测试账号

所有预设账号密码均为 `demo12345`。

| 邮箱 | 用途 |
|---|---|
| `demo@example.com` | 正常登录、报价、扣积分和任务完成 |
| `low@example.com` | 积分不足 |
| `fail@example.com` | 执行失败并退回预扣积分 |
| `slow@example.com` | 慢速任务，测试停止和取消 |

也可以在登录窗口注册任意测试邮箱，新账户自动获得 1000 模拟积分。

## 推荐测试顺序

### 正常任务

1. 使用 `demo@example.com` 登录。
2. 配音执行方式选择“集群 GPU”。
3. 选择任一模拟音色，输入短文案并刷新报价。
4. 开始生成，观察排队、配音、下载和本地合并过程。
5. 完成后确认右上角积分减少，最终音频和字幕正常生成。

模拟服务优先返回整合包内 IndexTTS2 自带的真人示例音频；它只用于验证音色试听、
下载和拼接，不会根据新文案重新合成语音，因此不代表集群的实际生成效果。

上传自定义音色后，模拟任务会把用户上传的参考音频标准化为 24 kHz 单声道 WAV，
并作为任务结果返回。这样可以验证“上传、选择、创建任务、下载、合并”的完整链路，
但仍不会让参考音频朗读输入文案。

### 积分不足

使用 `low@example.com` 提交任务。预期结果是任务在云端创建前被拒绝，页面明确显示积分
不足，本地流水线不能继续花费其他模型费用。

### 失败退款

使用 `fail@example.com` 提交任务。任务会先进入运行状态，随后模拟 GPU 故障。预期结果
是任务失败、流水线停止、预扣积分完整退回。

### 取消任务

使用 `slow@example.com` 提交任务，在任务运行期间点击“停止生成”。预期结果是云端任务
变为 cancelled，预扣积分退回，用户可以立即开始新任务。

## 重置数据

访问 `http://127.0.0.1:8030`，点击“重置模拟数据”。也可以关闭测试启动窗口后重新
启动，内存数据会自动恢复初始状态。

## 对接正式服务器

正式服务器严格实现《集群云端加速接口文档》后，不需要修改前端业务逻辑。发布时把
便携版内部配置改为：

```env
CLOUD_API_BASE_URL=https://正式域名/api/v1
```

然后使用正常的 `start_windows.bat` 启动。上线前至少重新验证登录、Token 刷新、报价、
幂等提交、积分预扣、完成结算、失败退款、取消、音色查询和音频下载。

模拟服务位于 `dev/mock_cloud_api.py`，只用于开发和内测，不应部署为正式收费服务。
