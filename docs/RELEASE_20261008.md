# 2026.10.08.1 制作桥、分镜编辑与内置引擎管理

本次代码更新增加通用 Codex 制作桥（含随包操作 Skill 和局部返修接口）、
分镜字幕归属调整、拆分与合并、单镜及批量修改确认。保留已有图片和视频，
用户确认编辑后再提交生成。

参考图在规划和重绘页面可查看；场景资产与分镜共用编辑器，上传替换图按完成素材处理。
图文和动态视频的共用场景参考逻辑同步修复。H3 转换以最终视频提示词为创作依据，
清除旧转换缓存，修复单行六段输出误补重复段落。

画面编排提供 15 秒／30 秒规划上限；初次规划按所选上限协调分镜，手动编辑长镜头
保留用户选择。使用视频 API 时需确认所选模型支持请求时长。

内置 ComfyUI 的管理、自动启动、模型检查和安装指引随代码更新。用户节点放在
根目录 `comfyui_plugins`，引擎额外加载此目录。安装后关闭并重启内置引擎，
在工作台重新检查实际加载节点。SelfLift 未捆绑，缺少它只影响依赖它的工作流。

普通 Launcher 更新保护 `runtime` 和 `models`，因此本次代码 ZIP **不安装 ComfyUI
独立 Python、CUDA 依赖或模型权重**。已有内置组件的整合包可使用上述管理功能；
没有组件的用户仍使用外部 ComfyUI 或视频 API。完整引擎组件包另行发布。

发布包含公共桥接的五个文件。用户停用标记、第三方插件、用户节点、项目、
密钥和模型保持。私人导演规则和医学制作 Skill 不进入公开更新。

验证：654 项后端回归通过，1 项环境条件跳过；前端生产构建通过；
本机内置引擎启动并加载全部 30 类工作流必需节点，额外节点搜索路径已生效。
便携升级夹具验证公共插件写入及用户文件保护；测试隔离了运行中服务的端口检查。
