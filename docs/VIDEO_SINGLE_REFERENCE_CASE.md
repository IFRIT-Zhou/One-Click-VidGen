# 单张核心参考：2026-09-17 成功案例与评估基准

## 已观察到的结果

用户用自己设计的单张复合参考图，加上人工整理的阶段视频提示词，获得了认可的成片。此结果验证这对输入足以支撑目标表达；并不证明旧 Agent 已能自动产生同等设计，也不能推断模型编码器结构。

单图里有主讲人、周围观众、主讲人的日韩景观气泡、观众的指责与战争想象。它没有长城与兵马俑，视频仍按提示词生成后段国内景观与欢呼。这直接反对“核心图只能含一个阶段的素材”和“所有后续内容必须先出现在图里”两条强约束。

同次三格图测试后段出现了分格排版。两张参考图的构图、素材细节也有差别，因此一组输出不足以单独衡量多格策略的普遍优劣；本项目按用户选择先落实单图路线。

## 原始输入与复现信息

用户图像提示词：

> 简笔火柴人，黑色钢笔轮廓线，简约手绘，一个红色衣服的小人站在演台中央，周围坐着很多观众围观他的讲话，他的脑袋上有个对话气泡框，里面是日本和韩国的标志性景观。观众表情惊讶紧张，观众们头上也有一个气泡框，里面是汉奸、不爱国，还有飞机战火
> 本图旨在：表示当下中国普通人对于日韩旅行的刻板印象

实际视频提示词为 `tools/test_seedance_reference_ab.py` 中 `VARIANTS['single']['guide'] + SHARED`。测试使用 Seedance 2.0 Fast 多模态接口，12 秒、720p、16:9、seed=9172026、静音。提示词、参数、参考图内容合成的已核对指纹为 `d54b108e2bc6cae017b90a5f82d5b2347dc14f565ea81e7bdeaf7529cb57b7c6`。视频输出为 `test/reference_ab_single.mp4`；这是手工样本，未由新 Agent 团队生成。

固定的视频开头：

> 图1是单张复合内容参考，不是必须照搬的首帧，也不表示所有内容同时存在。按提示词把图中的元素拆成先后阶段，输出始终是普通全屏视频。

生产侧两个导演使用的样例存于 `backend/app/video_director_examples.py`，只学习关系、信息归属和时序的方法；用户当前文案、人设与画风优先。阀门过程、家务照护等只是防止照搬会场的解释例子，不是已经跑过视频的成功样本。

## 将来评估自动规划时看什么

补充观察（2026-09-17）：用户重看成功样片，发现尾段有返回近似参考图构图的现象。
原始测试提示词描述了第三阶段欢呼和尴尬微笑，但未明确规定保持该结束状态；目前不能仅据此确定回返原因。
生产侧要求 ending_prompt 描述具体结束状态及尾部停留，不以“恢复参考图”替代结局。
气泡和图案允许到视频中按阶段生成，核心图不必预画所有气泡，也不强制全部去除；需后续实际样本验证。

规划交接修复：Agent3 若将 reference_visual 错填为纯图号，回用 Agent2 的具体设计；仅恢复该设计明确引用的已登记短字。
提示词文字比对经过一次局部修订仍有差异时，保存提示词并显示逐镜核对提示，继续完成视频定稿。
镜头/字幕/阶段结构、引用与非空等执行约束仍需通过。每次可用的定稿候选都会保存，后续失败可查看编辑。

1. 只给原文与任务设置，Agent 是否能自行选出具体场面，保留“谁提出、谁回应、为什么变化”，而非只写抽象结论或大标题。
2. 核心图是否以前段有内容的场面为主，主体、姿态和辅助信息归属清楚；有用的复合素材可保留，未来互斥的物理状态不直接叠在同一个实体上。
3. 视频提示词是否完整说明动作与反应、内容出现/消失和最后结果；允许必要切镜，不要求逐字卡点，也不必添加配音。
4. 是否保留原文事实、否定、引用和主观想象的边界；是否因为参考图未画某物而漏掉后续必要表达。
5. 换成无人物机制、生活事件或其他画风后，是否仍按内容设计，不机械复用“讲台—气泡—恐慌—欢呼”。

先检视自动输出的两份提示词，再用需要验证的样本做付费生成。离线回归覆盖数据与提示词交接、版本兼容、阶段完整和原时间轴；不能用测试通过数代表模型的视觉成功率。
