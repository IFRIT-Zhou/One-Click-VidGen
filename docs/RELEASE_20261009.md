# 2026.10.09.1 正式更新

动态视频和图文视频经本地案例测试后，本轮功能纳入正式更新。

## 用户更新

关闭正在执行的任务，通过 OCV 启动器检查更新。更新保留项目、API 配置、模型、本地引擎、第三方节点及私人插件，不会自动生成或扣费。

源码更新包含 Codex 制作桥、内置引擎管理界面、模型缺失检查、讲解模式和相关修复，不等于包含大型运行环境或权重。

## 可选组件

- `plugins/`：OCV 插件，包括通用 Codex 制作桥。
- `comfyui/engine/`：内核与独立 Python；`comfyui/custom_nodes/`：扩展节点。
- `tts/`：本地配音组件。
- `models/comfyui/`、`models/tts/`：统一模型目录。

旧版目录仍兼容，不需要在更新时手动移动大型文件。安装、迁移和分包说明见 [可选组件说明](OPTIONAL_COMPONENTS.md)。本次公开更新不含 SelfLift、第三方引擎二进制、模型权重或私人医学内容；可选整合包单独准备。

## 讲解模式

在动态视频参考图设置中启用讲解模式并指定人物。规划时只有明确出镜开口的镜头使用本镜配音作为口型参考，空镜或不说话的角色不自动注入。已有项目可逐镜开启“本镜讲解员出镜开口”，保存后重新生成相关视频，不必重做全部镜头。

此功能要求具有参考音频输入的 ComfyUI 工作流；内置 H3 已适配。视频 API 暂不自动注入，界面会提示切换支持的生成方式。音频注入不保证模型每次口型完全准确，建议先试单镜。最终旁白仍使用项目确认的原配音。

## 兼容修复

包括人物参考绑定、候选规划格式重试、同音识别误差引起的单句重配对齐失败；对齐所需 pypinyin 0.55.0 以原始 MIT 许可离线包随包附带，旧便携版无需联网装依赖。另同步云端号池、图像质量设置和桌面密码找回功能。
