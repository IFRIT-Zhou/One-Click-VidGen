# 音色头像目录

此目录用于存储音色头像图片。

## 使用说明

1. **支持的格式**: JPG, PNG, WebP, SVG
2. **推荐尺寸**: 128x128 或 256x256 像素
3. **命名规范**: 使用描述性名称，如 `male-young.png`, `female-cute.png`

## 如何添加头像

### 方法1：直接放置图片文件
将头像图片直接复制到此目录下，系统会自动扫描并加载。

### 方法2：通过界面上传
在音色库管理界面上传自定义头像。

## 预设头像

您可以从以下渠道获取音色头像：
- 从其他TTS平台截取头像
- 使用AI生成头像（如 Midjourney, DALL-E）
- 设计师设计的专业头像包
- Iconfinder, Flaticon 等图标网站

## 目录结构

```
avatars/
├── README.md          # 本说明文件
├── default.png        # 默认头像
├── male-*.png         # 男性音色头像
├── female-*.png       # 女性音色头像
└── custom-*.png       # 自定义头像
```
